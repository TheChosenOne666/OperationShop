## 2. 通用红线（每件生成前逐条确认，生成后逐条打勾）

> 完整版见 `资产基准模板与生成提示词.md` §1.7（A1–A14 + B/C/D/E 分表）。以下为**最容易翻车的 8 条**：

1. **背景 = 单一纯色高饱和幕布，出图按 `#FF00FF` 要求**，无渐变、无纹理、无阴影。出现渐变或杂色 → **直接重出**，不要硬抠（硬抠必然毛边）。
   ⚠️ 2026-09-19 更新：**验收已改为按图取键色**（`资产基准模板` §1.7 A11）——实测豆包连续两次把 `#FF00FF` 画成玫红，属模型色名理解偏差。四条机器判据是：**幕布可定位**（边缘带 ≥50% 落在实测键色 ±96 内）、**平整**（边缘带到键色 L1 的 95 分位 <24；真图实测 6–16，合成 8% 渐变 31–55）、**高饱和**（通道极差 ≥60）、**覆盖 ≥5%**。色名偏差不再退回；但**幕布上不得有投影色块**，那条照样退回。
2. **画面内无任何文字 / 汉字 / 字母 / 数字 / logo / 水印**（招牌板、黑板、书脊、花器上都不许有）。平台角标现由管线**自动剔除**并按面积分级（≤2% 记 WARN 后继续入库，>2% 记 FAIL 退回），**但这只是兜底**：画面**内部**的文字（招牌、书脊、黑板）机器判不了，仍属 A12 人工项，出了就得重出。**自行擦除水印时请用周围幕布色填**，别用白/黑或半透明涂抹，否则会留下假主体或洞。
3. **正视图平视**：立柱垂直线互相平行，可见侧面 ≤ 宽度 8%。出现斜视 / 俯仰 / 等距 → 重出。
4. **光源左上 30–45°，影落右下**，只有接触影，不画长投影；**阴影不得溢出到幕布上**。
5. **不用棋盘格表示透明**（这是本轮要根除的老问题）。
6. **咖啡立绘严格单层**（不得出现上方住宅楼层）。
7. **主体不得触碰画布边缘**，四周留纯色边距（贴边＝被裁掉一块，或幕布上有投影）。
8. **金币类图标保留 `$`**（唯一允许的货币符号例外；其余图标内不得有任何字符）。

## 3. 交付方式（给我什么、怎么给）

| 项 | 要求 | 原因 |
| --- | --- | --- |
| **格式** | **PNG（必须）**。不要 JPG | JPEG 有损压缩会在纯品红背景上产生噪点与色偏，直接导致键色抠像毛边、边缘残留 |
| **分辨率** | 给**原始高分辨率图**（短边 ≥ 1024），**不要自行缩放到交付尺寸** | 缩放与裁切由管线统一做，先缩后裁会损失质量 |
| **候选** | 每件 **3–4 个候选**，命名加后缀区分（如 `bg_mall_base_c1.png`） | AI 生图有随机性，一次命中不现实 |
| **文件名** | 直接用资产名（`<资产名>.png` / `<资产名>_c1.png`） | 便于管线自动识别目标尺寸 |
| **放置位置** | 建议 `D:\lingou-codex\game-operation\.work\incoming\`（该目录已在 `.gitignore` 内） | 避免污染 `git status` |
| **交付动作** | 告诉我路径即可，我跑管线 **`tools/m03_ingest.py ingest`**（品红键控 → 去溢色 → 1px 腐蚀去毛边 → 包围盒裁切 → 等比适配降采样 → 客观自检 → 择优入库 → 回写本表 §5 进度） | 缩放与判定一律由管线统一做，避免逐张手工处理产生基线差 |

> 🤖 **已建成的自动把关（2026-09-19，`tools/m03_ingest.py`）**：以下四条现在是**机器判定项，不合格会被直接退回**，出图时请当硬约束对待——
> ① **必须是 PNG**（JPG 在品红底上的压缩噪点会导致键控边缘发毛）；② **短边 ≥1024**（请勿自行缩放到交付尺寸）；③ **背景为单一平整高饱和幕布**（按图实测键色，判据见 §2 红线 1；渐变/纹理/棋盘格即判重出）；④ **主体不得贴画布边**（贴边＝门面被裁掉一块，或幕布上有投影）。
> 其余需人眼判定的条目（正视图透视、光源方向、橱窗自发光、有无文字、构图要素）在管线收尾时会打印成**「人工待勾」清单**，不会被自动放行。

> 🟫 **现在不急（2026-09-19 改道）**：13 件路径已被**占位图**占住（`python tools/m03_placeholder.py`，几何与交付尺寸逐件一致、`check` FAIL 0 项），M04 客户端工程已可并行开工。真图**什么时候出都行**，出图后丢进 `.work/incoming/` 跑 `ingest --apply`，管线会**原地覆盖同名占位文件**并勾掉 §5 进度表，工程侧不用改任何东西。
