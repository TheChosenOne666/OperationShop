## 4. 两项裁决说明

**（1）`平台事实核对.md` L142 的资产数：指向权威源，不复制数字。**
资产量是**设计/美术决策**，不是平台事实。`平台事实核对` 的职责是记录平台侧事实（API 限制、包体上限、授权规则）；把美术资产口径复制进来，等于制造一个**会随《美术圣经》改版而漂移的副本**。故改为"资产口径以《美术圣经》§7.6 为准"，**指向权威源而非复制它**。

**（2）ADR 0001 与 ADR 0002 的处理方式为何不同。**
- **ADR 0002** 的「随附决策：放宽未开业店铺校验」是一节**独立决策**，且前提（引入关店）已消失 → 用「⚠️ 已作废（2026-09-14）」标记，**保留历史正文供追溯**（决策记录的价值在于可回溯）。
- **ADR 0001** L38 位于「后果 → 收益」节，是一个**说明性括号里的举例**，陈述的是**当前仍成立的架构原则**（"所有写操作走同一套原子操作"），并非独立决议 → 直接**改枚举**为「解锁 / 升级」并注明移除即可，不适用"作废标记"。
- 原则：**作废标记用于"独立决策的前提消失"；改正文用于"举例/枚举含已移除项"。** 不可把 ADR 0002 的做法无脑套到所有 ADR。
