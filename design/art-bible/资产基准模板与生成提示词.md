## 0. 本文档要解决的问题

现有 19 张素材**不能作为基准**，因为每一张都在**不同的画法**下生成：

| 现有素材的问题 | 后果 | 本文档的对应解法 |
| --- | --- | --- |
| `1.jpg` 是写实透视外景、`2.jpg` 是室内商场、主界面图是正视图 | 三张的**透视与镜头完全不同**，无法拼合 | §1 锁定唯一基准与镜头规范 |
| `5.jpg` 书店偏冷、其余偏暖 | 并排时色温断裂 | §1.4 锁定光照与色温 |
| `8.jpg` 咖啡含两层住宅 | 与单层铺位**不等高**，无法并排 | §2 逐资产规定构图变体 |
| `3/4/5/9` 的雨棚有无、形状各不相同 | 五个铺位顶部**没有统一的视觉节奏** | §1.5 统一模板决策（全部带雨棚） |
| 19/19 都有 AI 水印，且**恰好压在右下角** | 与美术圣经 §4.4 的 8% 安全框冲突 | §3 提示词内置"无水印无文字" |
| 19/19 的"透明"是**棋盘格烘焙进像素** | 抠图毛边、无法直接用 | §3 提示词内置"纯品红背景 + 禁止棋盘格" |
| 所有中文都是烘焙像素，`14.jpg` 还印有 AI 乱码 `TINAINA` | 改不了、不能多语言、不合规 | §3 提示词内置"画面内不得出现任何文字/字母" |

**核心思路**：把"一致性"从**事后修正**（抠图时逐张对齐）前移到**生成端约束**（提示词里写死基准）。这样"任何来源的素材"都能落在同一套基准上。

## 1. 资产基准模板

### 1.1 唯一基准声明

> **基准画面 = `design-image/主界面图.jpg`（1080×1918）的正视图平面构成。**
> 凡与基准冲突的参考图，**一律以基准为准**，冲突图降级为"色彩与材质参考"，不作为构图依据。

- `1.jpg` → 仅作"绿雨棚 / 木门 / 空橱窗"的**材质与配色参考**，**不采用其透视**。
- `2.jpg` → 仅作"木栏杆 / 暖光橱窗"的**灯光参考**，**不采用其室内商场构图**。
- `3/4/5/8/9` → 仅作各店的**内容物参考**（卖什么、摆什么），**构图一律重排到本模板**。

### 1.2 基准画面尺寸与安全框

| 项 | 规格 |
| --- | --- |

### 1.3 立绘构图镜头规范【最关键的一节】

AI 生图最容易跑偏的就是镜头。以下为**硬性数值**，任何一条不满足即**返工重出**：

| 规范项 | 要求 | 判定方法 |
| --- | --- | --- |
| **视角** | **正面平视（eye-level straight-on）**，镜头正对店铺墙面法线 | 店铺左右立柱的垂直线**互相平行**（不收敛） |
| **透视** | **单点透视，灭点位于画面水平正中**；**纵深压缩到接近正交（正面投影）** | 可见的侧面宽度 **≤ 店铺宽度的 8%**；超过即判为"斜视"返工 |
| **地平线高度** | **位于画布下缘（y = 100%）**，即**不露天空、不露地面纵深** | 立面（含雨棚）占画布高度 **≥ 88%** |
| **地面带** | 底部只保留**接触影 + 一级台阶**，占画布高度 **≤ 10%** | 超过即判为"街景图"返工 |
| **上下留白** | 顶部 ≤ 4%、底部 ≤ 4% | — |
| **墙面占比** | 立面高度 ≥ 88%（见上）；橱窗宽度占立面宽度 **55–70%** | — |
| **禁止** | 等距 / 俯视 / 仰视 / 两点透视 / 鱼眼 / 景深虚化 / 斜 45° 转角 | 出现任一即返工 |

> **为什么把"纵深近乎正交"写死**：主界面是 5 个铺位横向并排。只要任何一张带明显的侧视纵深，它在并排时就会"侧过去"，与邻居不在同一朝向——这正是 `8.jpg`（转角楼）无法使用的根本原因。

### 1.4 光照与色温规范

| 项 | 规格 |
| --- | --- |
| 时间 | **傍晚 golden-hour**，固定不变。**禁止夜景、正午、阴天** |
| 主光方向 | **左上方 30–45°**，影**向右下** |
| 主光色温 | ≈ **3200–3800K**，暖橙叠加 `#E8A868` |
| 辅光（自发光） | 橱窗/室内暖光**无方向**（点光源感），≈ **2700–3000K**，色 `#F2DDAE` |
| 亮度关系 | 橱窗自发光**高于外墙 1.5–2 档** |
| 阴影 | **只做接触影**：软、短、**不透明度 ≤ 25%**；**禁止长投影**（会与相邻铺位打架） |
| 暗部 | 用暖灰棕 `#9A8272` 收尾，**禁止纯黑** |

### 1.5 描线规范

| 项 | 规格 |
| --- | --- |
| **外套轮廓线宽** | **画布短边 × 0.8%** → 在 1024 画布上约 **8px** |
| 内部结构线宽 | 外轮廓的 **60%** → 约 5px |
| 描线色 | **暖深棕 `#4A2F1E`**（**禁止纯黑 `#000000`**） |
| 线宽一致性 | 同一张图内**所有物件线宽一致**；**不因远近变化线宽**（因无透视） |
| 描线风格 | 圆头、圆角连接；线宽**均匀**，不做粗细渐变 |

### 1.6 统一模板决策（相对现有素材的**刻意偏离**，需记录）

以下是"为了一致性而主动偏离现有素材"的决策，**不是遗漏**：

| 决策 | 现状 | 决策 | 理由 |
| --- | --- | --- | --- |
| **所有铺位统一带雨棚** | `4.jpg` 衣橱**无雨棚**、`5.jpg` 书店上楣是橄榄色板材 | **5 个铺位全部带雨棚**，形成统一的顶部结构带 | 正视图 5 铺位并排时，一致的雨棚带是把它们"缝"成一座商场的关键视觉节奏；缺失会显得"掉了一块" |
| **雨棚配色分工** | 各异 | 空铺 / 衣橱 / 书店 = **纯色暖绿**；甜屋 / 咖啡 = **橙白条**；花束 = **粉白条** | 保持主界面的雨棚色节奏（绿为主、条纹点缀），同时保住各店个性 |
| **招牌板一律留空** | 现素材招牌上无字（好），但主界面图烘焙了文字 | **所有招牌/牌匾留空木面**，文字由引擎文本层渲染 | 见美术圣经 §8.3：位图文字改不了、不能多语言、不能缩放 |
| **书店拉回暖调** | `5.jpg` 整体偏冷偏暗 | 上楣改暖木色、阴影改暖灰棕、提高橱窗暖光占比 | 与其余 4 店并排时的色温一致性（美术圣经 §2.4） |
| **咖啡裁到单层** | `8.jpg` 含两层住宅立面 | **严格单层**，与其它铺位等高 | 否则并排时高度不一致 |

### 1.8 强制流程与验收口径【v1.1 新增 · 本轮核心专业判断】

> **本节把 §1 的规则从"文档约定"变成"制作流程强制"。**
> 依据：美术圣经 附录 A.1 第 3 条 + 附录 B.1 第 6 项（用户已授权采用）。

#### 1.8.1 三个"强制件"

流程强制不能只靠一句"请遵守"，必须落成**可检查的三件东西**：

| 强制件 | 形态 | 存放位置 | 作用 |
| --- | --- | --- | --- |

#### 1.8.3 逐资产验收口径（客观、可判定）

> 「判定方法」一栏是**可被第三人复核的客观条件**，不是主观描述。任一不满足 → **返工**。

| 资产类别 | 关键验收项 | 判定方法（客观） |
| --- | --- | --- |
| **全部** | 正视图 | 立柱垂直线**互相平行**（测：左右立柱顶端 x 差 ≈ 底端 x 差，误差 ≤ 2%） |
| **全部** | 光源左上 | 接触影**落在主体右下方**（测：影质心相对主体质心的 dx>0 且 dy>0） |
| **全部** | 无文字 | **OCR 检出 0 个字符**；或人工确认无字母/汉字/数字 |
| **全部** | 无棋盘格 | 背景像素**方差 ≈ 0**（单一纯色）；非背景区无"白灰交替"图案 |
| **全部** | 描线色 | 最暗描线像素落在 `#4A2F1E` ± 容差；**无 `#000000`** |
| **全部** | 色板 | 主体像素色相**不落入蓝/青/紫/洋红区间**（背景键色除外） |
| **背景 / 底图** | 安全区 | 顶部 48px、底部 HUD 区（y≥1174@750）内**无任何信息元素** |
| **立绘** | 单层 | 立面高度占比 ≥ 88%；**无第二层结构**（咖啡尤其） |
