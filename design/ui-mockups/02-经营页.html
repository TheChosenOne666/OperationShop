经营页 · 设计说明

为什么这样排

  • 列表顺序 = 客流到店顺序（咖啡→花束→衣橱→甜屋→书店），玩家一眼看出"客人下一步去哪家"
  • 顶部三个数：客流 / 今日收益 / 满铺加成状态——正好回答"我现在赚多少、为什么"
  • 关店按钮已移除（用户拍板）。营业中的店只显示状态，不给"只能变差"的操作

尺寸要点（@750）

  • 概览卡 706×112，三格等分
  • 店铺行 706×146，行距 8px，5 行共 762px
  • 缩略图 104×104，圆角 9，描边 3px
  • 「开业」按钮 132×80，触控区向下扩到 ≥88 高
  • 底部 HUD 160px + 其上方 53px 禁放区

三通道状态编码

  • 营业中：绿色对勾圆形（形状）+ 文字「营业中」
  • 待开业：金色加号角标 + 「开业」按钮
  • 未开放：木牌锁形 + 文字「未开放」+ 缩略图去饱和（明度）
  • 未开放行禁止变红——红=危险，违反"无失败态"红线

数值口径（本图示例，全套设计稿统一）

  • 金币 1012 / 今日客流 38/50 / 今日收益 +332
  • 来自：初始 1280 − 解锁衣橱 600 = 680，加上今日 24×8 + 14×10 = 332
  • 咖啡 Lv2：基础 7 + 满铺 1 = 单客 8；累计 24 客流 → 192 金币
  • 花束 Lv1：基础 9 + 满铺 1 = 单客 10；累计 14 客流 → 140 金币
  • 衣橱 Lv1：基础 12（二层未满铺，无加成）；尚未开业，累计 0
  • 单客收益必须写明「基础 + 满铺」的构成，否则玩家看不懂数字为什么变了
