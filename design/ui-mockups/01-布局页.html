布局页 · 设计说明

尺寸要点（@750 基准）

  • 顶部避让区 48px 不放任何信息（避系统胶囊）
  • 左右安全边距 22px，内容宽 706px
  • 二层铺位卡 228×279，卡间距 11px（墙垛）
  • 一层铺位卡 347×319（两层等宽，不做透视缩放）
  • 底部 HUD 160px 独占 + 其上方 53px 禁放区
  • 所有可点元素触控区 ≥88×88

状态编码（转灰度后仍须可分）

  • 未开放：纱罩 #CFC6B8 @35% + 自发光 30% + 锁形角标 + 文字「未开放 · 800 金币」
  • 待开业：自发光 100% + 加号角标 + 文字「待开业」
  • 营业中：店招有形 + 单客收益文字
  • 未开放与待开业不靠颜色区分——靠锁 vs 加号、暗 vs 亮、文字，三通道

主按钮三态

  • 可解锁（本图）：金色呼吸光晕 + 加号角标 + 「600 / 800 金币」
  • 金币不足：不透明度 78%（仍 ≥3:1）+ 锁角标 + 文字改「再攒 N 金币」
    禁止变红（红=危险，违反无失败态）、禁止灰到看不见
  • 按下：下沉 2px + 内阴影 + 亮度 −12%，80ms，色相不变
